# Battle City Remake

A Java remake of the classic **Battle City / Tank 1990** game.

This project was developed as a **Yeditepe University CSE212 Software Development Methodologies** term project, but the main goal was to recreate the feeling of the original retro tank game as a playable Java remake.

## About

The player controls a tank, destroys enemy tanks, and protects the base from being destroyed.  
The game includes multiple levels, destructible walls, enemy AI, power-ups, score tracking, and a simple map editor.

## Features

- Classic top-down tank gameplay
- Player movement with `WASD`
- Shooting with `Space`
- Enemy tanks spawning from the top of the map
- Bullet collisions with walls, tanks, and other bullets
- Destructible brick walls
- Steel walls and tank upgrades
- Animated water and bush overlay system
- Player lives and respawn system
- Pause / unpause button
- Game over and level complete screens
- Power-ups inspired by the original game
- High score saving with CSV
- Custom map editor

## Controls

| Key | Action |
|---|---|
| W | Move up |
| A | Move left |
| S | Move down |
| D | Move right |
| Space | Shoot |

## Goal

The goal of this project was to rebuild Battle City in Java while practicing object-oriented game development, Swing GUI programming, collision handling, game states, file operations, and a basic custom game loop.

## Note

This is a student-made remake created for educational purposes.  
It is not an official Battle City release.
